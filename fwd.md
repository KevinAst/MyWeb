# `fwd` Directory

The `fwd/` directory is merely a "convenience copy" of all FireWithin
source code that contains the unauthorized devotions.

You can find this source image through the git tag: archive-daily-devotions

- to refresh your workspace from this tag:
  ```
  $ git checkout archive-daily-devotions
  ```

- OR: if you simply want to browse the old source without changing branches:
  ```
  # KJB: I think the makes a copy of the source to your designated file
  $ git show archive-daily-devotions:path/to/file
  ```
